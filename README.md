# Bee Hatcher
In this simple little game, you unlock bees by hatching them!


# How to play 
You unlock your first bee by buying an egg, and then pressing the fields! 

Different bee types have different boosts and collection amounts on different fields, so experiment! 

Click on a bee to use up a royal jelly to then change it to a different type!

You can buy tools in the shop to increase pollen gain further.

Using items adds to the multiplier bonus that you get when using the right bee types
